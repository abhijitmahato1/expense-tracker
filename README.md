# Expense Tracker 💰

A modern and responsive Expense Tracker web application built with HTML, CSS, JavaScript, Supabase, and Supabase Authentication.

## 🚀 Features

- Add, edit, and delete transactions
- Track income and expenses
- Automatic balance calculation
- Search and filter transactions
- Custom expense categories
- Expense breakdown chart
- Cloud data storage with Supabase
- Secure user authentication
- Login, signup, logout, and password reset
- User-specific transactions with Row Level Security (RLS)
- Responsive design for desktop and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase
- Supabase Authentication
- Git & GitHub
